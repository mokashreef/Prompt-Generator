# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Privacy-First Security Model

Prompt Generator is designed from the ground up with zero server-side components:
* **No Remote Telemetry:** No user input or generated text ever leaves the user's browser.
* **No AI Service Integrations:** The application never requests or stores API keys for OpenAI, Anthropic, Google, or any other vendor.
* **No Remote Code Execution:** The Chrome Extension runs exclusively via bundled, local scripts under Manifest V3 and CSP regulations.
